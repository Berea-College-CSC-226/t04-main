2.f. Define Each Term:
```
        a. Clone:       You make an exact copy of the main repository onto your computer

        b. Commit:      You submit your changes into the main history of the project.

        c. Push:       You send your local commits to the remote repository on Github

        d. Branch:     You make a different space aside from the main one to work on changes separately.

        e. Pull:       You download updates from the remote repository to your local machine.

        f. Pull Request:A request asking others to review and merge your changes into the main branch.

        g. Merge:       You combine changes from one branch into another.
        
        h. Remote:      A version of the repository stored online like on github
        
        i. Local:       The version of the repository stored on your own computer.

        j. Fetch:       You download new data from the remote without merging it yet

    Check your definitions against the [git glossary](https://help.github.com/articles/github-glossary/) 
    to ensure they are correct.
```
